# 运输船：暮雨行动

结合运输船团队枪战原型与“几猫”雨后港区视觉思路的浏览器 FPS。原地图、角色和武器系统以 [riba2534/claude-opus-5-5-demo 的 cf-transport-ship](https://github.com/riba2534/claude-opus-5-5-demo/tree/main/cf-transport-ship) 为基础进行改造。美术参考为用户提供的《几猫国产3A大作_V1.html》。属于非官方致敬作品。

## 试玩与离线版

- 在线试玩：https://harbor-after-rain-k7m4.minarryli.chatgpt.site
- 离线版：[下载单文件 HTML](offline/harbor-after-rain-v1.4.9.html)，保存后用 Chrome / Edge 直接打开，无需服务端。
- 当前版本：1.4.9。源码、构建脚本和测试均在本仓库。

## 运行

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4173 。也可以直接在现代浏览器打开 `dist/index.html`；所有运行所需代码与资源均在该文件中，声音在点击开始后启用。推荐桌面 Chrome / Edge，移动设备使用流畅画质。需要 WebGL 2。

## 模式与操作

- 启动页直接展示两张玩法卡，附交火／占点示意；点击对应入口即可开局，两种玩法共用部署设置。
- 两种模式均为最多 3 分钟，暂停不计时；到时高分获胜，同分为平局，先达到目标可提前结束。
- 团队竞技：4v4、5v5 或 8v8，率先达到目标击杀数获胜。
- 中继争夺：进入标记区域占领中继，占领需要约 7 秒；控制后每秒 +1 分。双方同时在圈内时停止占领与计分，每 75 秒转移据点。墙体遮挡和出生保护中的角色不参与占领。
- WASD 移动；鼠标转向；左键开火；按住右键举枪瞄准（步枪／冲锋枪／手枪），狙击右键切换倍率，刀右键重击。
- R 换弹；1–4 切武器；Q 上一把；空格跳跃；C 下蹲；Shift 静步。
- B 配装（出生区即时更换，其他位置下次重生生效）；F 检视武器；Tab 计分板；Esc 暂停。
- 触屏仅支持横屏：左拇指在左下区域按住滑动移动；右侧空白处滑动转向，按住右侧「开火」并拖动可边射击边瞄准。点「瞄准」「蹲」切换状态。浏览器不允许鼠标锁定时可按住鼠标拖动视角。

## 本次改造

### 1.4.9 移动端仅支持横屏

- 进入、开始或继续游戏时，浏览器允许则尝试全屏并锁定横屏；不支持或拒绝时显示手动横放提示。移动竖屏覆盖菜单与游戏，隐藏触控按键。
- 对局中转成竖屏会暂停计时并清空所有按住的操作。回到横屏仍保持暂停，点击继续后重新落指操作，避免误走、连射。
- 桌面窄窗口不受横屏限制，不会自动请求全屏；保留上一版双拇指移动、拖动开火与多指按钮操作。

`npm run test:landscape` 检查转屏、暂停与输入清理，以及独立模拟的方向 API 调用路线。`npm run test:mobile` 在三种横屏尺寸、两种玩法中检查真实浏览器多点触摸；浏览器模拟不等同于真机系统旋转。

### 1.4.8 移动端双拇指操作

- 右侧主开火键可按住拖动瞄准，让两根拇指同时完成移动、转向和射击。移动、视角与按钮各自保留手指归属，多指按住开火时，松开其中一指不会误停另一指。
- 左侧摇杆随落指位置展开，轻微抖动留在死区内，超出范围后限制最大速度。右侧视角手指交接时从当前位置继续，避免镜头跳动。
- 暂停、配装、切后台、旋转屏幕、死亡和重开都会释放触控状态，恢复后需要重新按下，防止误走和连射。
- 左拇指仍按住时，右手也可操作暂停菜单的继续、退出和确认按钮；拖出按钮再松开不会误触。手机切枪键循环可用武器，包括刀和手雷。
- 按键改为横竖屏自适应布局，预留安全区并显示开火、瞄准和蹲下状态；移动端说明同步到菜单与暂停页。保留桌面键鼠操作。

`node scripts/mobile-controls-check.mjs` 使用浏览器原生多点触摸事件检查实际移动、转向和弹药变化，并覆盖不同屏幕尺寸、两种玩法以及中断后的输入释放。

### 1.4.7 敌我姓名与弹匣连接

- 以当前玩家的阵营为准，友军姓名为蓝色、敌军为红色；覆盖头顶、准星、击杀信息、计分板和结算。敌方头部被掩体挡住时隐藏姓名，切换阵营后颜色关系保持一致。
- 补齐 M4 机匣与护木连接、各枪弹匣井和 MP5 握把／前准星连接；沙漠之鹰的实心握把改为有真实内腔的外壳，弹匣底板贴合握把。弹匣移走后仍能看到完整井口和内壁。
- 换弹分为退出、搬移、对齐和插入，弹匣尚在井内时不横移扭转；AK 沿前挂钩摇出／锁回，手枪沿握把倾角拔插。手掌跟随真实弹匣，保留原换弹时长、声音节点及动作结束后的手臂复位。

`node scripts/names-check.mjs --out artifacts/v147` 检查两种玩法、两种阵营、实际姓名像素、遮挡及资源释放。`node scripts/magazine-check.mjs --phase after --out artifacts/v147` 连续运行五把枪的真实换弹，保存关键帧、接触点和复位记录；原始第一视角与移开手臂的结构诊断图分开标注。几何测试使用实际模型表面和射线核对井口空腔及连接，避免仅依赖配置值。

### 1.4.6 右手握枪方向

- 修正右手腕朝上后方、连带肘部高于握把的反折姿态。保持食指和拇指在上、掌心朝握把内侧，围绕握把接触点校准右手方向，让手腕从右下方接入。
- 五种枪械分别校准腰射和举枪瞄准的右腕方向，中间状态连续过渡；保留刀和手雷原握姿。右食指单独求解到枪身侧面／扳机区域，沿用动作平滑和拉栓过渡，其余手指继续包住握把。
- 左手托枪与换弹回位逻辑沿用 1.4.5；右手的开火和狙击拉栓独立核对。

`node scripts/right-hand-check.mjs --phase after --out artifacts/v146` 对照真实游戏视角与明确标注的侧面诊断视角，并逐项校验左手姿态及前臂表面数据保持一致。

### 1.4.5 换弹后手臂回位

- 修复手掌已经回到护木、手肘却停留在换弹历史姿态的问题。握持姿态有独立的标准肘部目标；抓匣和拉柄仍保留连续关节解，回握过程中逐渐恢复目标，避免前臂扭转残留或瞬间跳回。
- 切换武器时清理上一把武器的手臂求解状态。取消动作后同样恢复当前握姿，保留半指手套、掌心承托和独立腕部旋转。
- 回归对照使用相同模拟时刻的未换弹角色，检查完整换弹、连续换弹及中途取消后的肘部、前臂朝向与实际表面顶点，避免把呼吸晃动当成姿态差异。

`node scripts/reload-recovery.mjs --phase after --out artifacts/v145` 生成回位对照；同时保留结束、结束后 0.2 秒和 0.6 秒的原始画面与测量。

### 1.4.4 掌心承托与独立腕部旋转

- 步枪支持手改为掌心向上、手指斜跨护木的浅托握；M4、AK、MP5、AWM 按各自护木底面设置接触点，手枪包握和刀、手雷动作单独保留。
- 前臂骨轴与手掌姿态分开求解，裸臂主体保持直线，短腕部过渡接入手套。翻掌使用完整过渡时间；托枪、抓匣、拉柄分别设置腕部轴向旋转，保留手掌相对前臂的活动。
- 狙击枪拉栓的接触点跟随机械拉柄，手掌朝向由枪身和独立抓柄姿态确定，避免直接继承拉柄转角造成反向折腕。
- 连续动作沿用上一有效手肘解，并限制转动速度；腕部角度目标允许适度让步，保持握点和两段骨长。展示场直接定格采用固定初始解，因此与连续回放的肘部姿态可能略有不同；动作连贯性以完整回放为准。
- 武器展示场显示左右腕弯曲角，导出实际前臂、相对手腕和手掌方向；检查这些旋转组合后与可见手掌一致。完整换弹记录逐个模拟步骤的关节运动，便于发现静态截图无法显示的跳变。

`node scripts/reload-motion.mjs --phase after --out artifacts/v144` 录制实际换弹的 33 帧可播放展示和逐步关节数据。`npm run compare:arms` 与 `npm run report:arms` 默认使用 v144；显式指定 `--out` 可保留旧版对照。浏览器回归检查仍使用 `npm run test:hands`。

### 1.4.3 挽袖前臂与自然腕部

- 第一视角改为挽袖露出前臂，保留半指战术手套。前臂有不对称肌腹、逐渐收细的尺桡侧轮廓和扁平腕部；中段保持骨骼方向，转折集中在肘、腕附近，避免整条手臂弯成软管。
- 皮肤沿用手指的独立材质与微纹理，短卷袖使用更明亮的卡其／灰蓝色织物。皮肤延伸到薄手套腕口内，旋腕时截面共同转动；腕扣贴合手套。
- 在相同实际游戏机位、默认视野和背光下保留改动前后对照，并检查抓弹匣、拉机柄及手枪握姿。自动检查覆盖腕部嵌合、肘部连接和多武器动作中的几何有效性。

`npm run test:hands -- --out artifacts/v143` 检查高／低画质动作与资源稳定性。`npm run compare:arms` 复拍真实游戏机位；`node scripts/hand-compare.mjs --phase after --out artifacts/v143 --only m4-hip,m4-reload45,m4-reload80,ak-grip-close,deagle-grip-close` 复拍五个补充姿态。保留对应基线后运行 `npm run report:arms` 生成六组对照页。截图中的帧率不作为性能基准。

### 1.4.2 第一视角半指手套与手型

- 手掌改为有掌宽变化、掌弓和拇指根体积的连续轮廓，手指分出收窄的指节、圆指腹与薄指甲。半指手套保留布料包覆、截边、掌面防滑层和扁平腕扣，露出的皮肤单独着色。
- 皮肤、指甲、手套、袖子分别使用非金属材质；皮肤微纹理和织物纹理独立生成，潮湿只改变表面参数。材质实例独立、贴图复用，不加载外部图片。
- 袖管收至手腕并跟随旋腕，使用不对称布料褶皱；手枪采用独立的双手包握姿态。保持握点、扳机指、弹匣抓取与机柄动作相连。
- 修复武器展示场直接打开换弹进度链接时叠加未完成抽枪姿态的问题；材质分组、握点与抽枪状态进入展示场自检。

`npm run test:hands` 检查高／低画质下七种武器、瞄准、射击、检视、逐帧换弹和重复切枪后的资源稳定性。`npm run compare:hands` 保存固定视角截图；与本机保留的 1.4.1 基线配合 `npm run report:hands` 可生成对照页。诊断近照与展开手型明确标注，区别于实际游戏镜头。

### 1.4.1 双玩法入口与三分钟对局

团队竞技与中继争夺改为平铺入口，各配简洁战术示意、规则、提前获胜目标与独立开始按钮。共享阵营、武器、人数和难度设置；保留展示场、操作指南和画面选项，移动端可滚动访问两个入口。

两种模式统一 180 秒。开局显示 `3:00`，最后一秒显示 `0:01`；到期先结算，再停止该步骤的射击、爆炸、延迟事件和据点计分。暂停与结算后不再推进时间，提前达标胜利保持有效。`npm run test:menu` 检查两个真实入口、三分钟完整模拟、胜负／平局、提前达标、暂停重开、手机触屏、键盘和离线版本。

### 1.4 材质、结构与末端后期

逐项机制、源码位置、取舍和展示入口见 [画面校对记录](docs/visual-upgrade-v1.4.md)。原作只读参考进一步拆成 12 个职责目录、449 个带行号的声明片段；本项目新增模块继续与正式游戏共用，不改变离线单 HTML 交付。

- 材质采用共享磨损遮罩，联动生成颜色、凹凸、粗糙度和金属度；各色箱体不再共用错位损伤法线，白色印字不再被猜测为裸金属。木纹/裂缝/钉头和甲板油迹分别参与表面响应，天气层保留原有干材质数据。
- 近处货箱与长侧舱采用真实梯形凹槽、空心角件、圆锁杆和铰链；侧舱门窗沿完整 UV 切片。远景维持简模、屋顶保留法线，碰撞边界与通道不变。M4 抛壳口改为真实开口与内腔。
- 全档增加末端 FXAA、受限锐化和末端颗粒；辉光首层加入亮度权重，阴影柔度使用一致世界尺度，光雾采用近密远疏步长。新增一个全屏通道，辉光及光雾不新增通道或采样步数。
- 材质展示场可独立看 ORM 与锈层；道具展示可切换立体/平面箱体；渲染展示可单独比较抗锯齿、锐化、阴影和辉光，全部保存到配置链接与 JSON。

`npm run test:surfaces` 检查真实材质通道、资源稳定性和箱体重建；`npm run test:post` 检查三档着色器和后期开关；`npm run compare:visual` 生成固定条件前后对照（需本机 1.3 基线）。`npm run study:reference` 生成参考片段索引（先运行原作审计）。

### 1.3 九模块展示场与可复现迭代

游戏菜单新增「九模块展示场」，也可直接打开 `?lab=render`。入口按本地参考源码注册表核对：`render / mats / props / level / backdrop / ground / fx / weapon / enemies`，与文章九类文件职责分组不完全相同。

- 九个独立三维场景：渲染标定、18种场景材质、共用道具阵列、实际地图导航、船体远景、遮雨与积水、六类材质命中、七种武器与逐帧换弹、角色动作与真实机器人绕障/视线子测试。原作展示模式将声音置空；本项目另设音效试听。
- 独立调参、固定相机、暂停、配置链接与 JSON 导出。用 `?lab=weapon&seed=4207&shot=1&t=2&q=high` 固定随机种子、时刻和画质；自动迭代接口见 `docs/lab-contract.json`。切换模块或重置会重载页面并释放上一场资源，随后等待 `__lab.ready`。
- `src/lab/scenes/` 每个展示场一个文件；`surface-materials.js` 和 `props.js` 从地图拆出，与实战调用同一套构造。构建继续输出可双击离线运行的单个 HTML，没有新增外部图片、模型或音效依赖。
- 正式游戏加入半分辨率接触遮蔽和混合高光映射，复用已有深度；雨量与湿度独立，停雨可保留湿地，雨圈随降雨停止；湿润材质增加细法线抗闪烁。货箱新增结构角件、门杆，油桶新增卷边与桶盖，继续按材质合批。
- `npm run test:lab` 逐场检查渲染、参数响应、固定时刻、六种命中特效、对象池上限与回收、七武器动作、低血量、战术子测试、离线和移动布局。源码审计摘要见 `docs/reference-audit.json`；原始参考代码和截图只在忽略目录保留，不打包发布。

### 1.2 扩展甲板与暴雨交火

- 作战甲板由 74 × 24.3 米扩为 74 × 36.3 米，面积增加约 49%。新增两条全长侧路、四间多出口维护舱、两处 2.6 米高且两端可上下的观察平台；原长集装箱通道增加横向舱门。雷达、出生点、据点、遮雨图、积水和船体宽度同步更新。
- 导航支持明确标记的楼梯与高台高度，限制台阶高度并保留地面通道；机器人按新路线分路。关键区域验证真实角色行走及头顶净空，不能直接从高台侧面寻路上台。
- 第一人称手套改为分节手指、拇指与连续手掌，补充护垫、掌纹结构、腕带和折皱袖管；握枪、托枪、抓弹匣、拉机柄分别设置手型，并让接触点随零件移动，使用双段手臂姿态和连续过渡。
- 普通击杀使用更清楚的重音与双音确认，爆头增加金属高频层，连杀逐级升调；自己阵亡时采用直接播放的重击、闷哼、倒地装备声和短暂耳鸣/闷音。普通命中提示不会与击杀提示重复叠放。
- 受击产生按来弹方向变化的俯仰、左右偏转和侧倾，弹簧回弹与短暂震动有幅度上限；实际弹道保持与受击后的瞄准方向一致。45 HP 以下逐渐出现红色边缘炫光、双拍脉动和心跳，复活清除。
- 暴雨包含近远两层雨线、阵风、水冠、弹起水滴、扩散雨圈及薄层贴地雨雾。遮雨按真实屋顶裁切，效果池和绘制批次有上限，流畅画质关闭雨雾。

### 1.1 材质与动作反馈

## 工程与验证

Three.js r186 + 原生 JavaScript/CSS + Web Audio；esbuild 打包成单 HTML。关键模块：`game.js` 对局，`render.js/env.js/atmosphere.js/weather.js` 画面，`guns.js/gun-detail.js/viewmodel.js/character.js` 模型与动作，`effects.js/impact-pools.js/audio.js` 命中与声音，`bots.js/tactics.js` 机器人，`relay-state.js/objective.js` 据点规则与表现，`physics.js` 碰撞导航。

```sh
npm test
npm run test:browser
npm run test:feedback
npm run test:extended
npm run test:arena
```

浏览器检查需要本机 Chrome 与已启动的预览服务器，包含加载、真实渲染、移动、暂停恢复、机器人交火和据点轮换；反馈检查使用真实鼠标／键盘操作验证瞄准与换弹，并通过真实弹道检查六类表面反馈和特效池上限。截图及日志输出到忽略目录 `artifacts/`。补充测试脚本检查移动布局、离线打开、连续重开和完整对局。程序化快进验证用于玩法稳定性，不等同于实时帧率测量。

扩图检查 `test:arena` 验证实际玩家穿越设备舱、沿楼梯上下平台、走完侧路，并检查受击镜头、低血量、击杀/阵亡/复活反馈；使用 OfflineAudioContext 渲染音效以检查非静音、信号限幅与击杀层次。

当前对局为本机玩家与机器人，不含真人联网、账号和云端存档。画质分档用于不同设备，实际性能取决于分辨率与硬件。
