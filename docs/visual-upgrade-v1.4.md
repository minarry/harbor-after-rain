## 为什么这些改动会影响画面

### 材质：一个磨损位置，多个物理响应

旧实现把最终颜色的明暗与色相用来推测锈层，白色印字可能被算成裸金属；不同涂装又共用侧板法线，锈斑位置和凹凸对不上。现在先生成损伤层，再同时写入颜色、凹凸和数据贴图。ORM 的 R/G/B 分别为表面遮蔽、粗糙度、金属度，A 为氧化/流挂遮罩；白字不再决定金属度。

新增贴图和材质携带可导出的 `pbrSource.schema=2`、种子与 `layerStats`。材质展示场按单通道显示灰度数据，且诊断视图关闭后期，避免把打包的 RGB 图片误认成粗糙度。可用同一链接恢复相机、湿度和通道。

原作使用 GPU MRT 生成多张贴图；本项目沿用启动时的 Canvas 与数值数组生成路径，数据图按画质降采样并生成 mipmap，随后复用于每帧渲染。ORM 的 alpha 是氧化数据，降采样按四个独立数值通道计算，避免 Canvas 透明合成把无锈区域的粗糙度和金属度一起擦除。

### 模型：优先改变轮廓、遮挡与零件关系

法线贴图能改变反光方向，不能改变侧视轮廓或真正开孔。货箱结构因此采用实几何：截面保持平面折边，角件开孔有壁厚，锁杆为圆柱。侧板使用细节法线，避免几何波纹和法线波纹重复叠加。仍按材质合批，不为每个铰链增加独立绘制。

原作 20099 附近的角件孔采用暗色贴片，本项目此次采用实际空腔；这部分是适配后的改进，不是对原作已有能力的描述。屋顶缺口只保留在角孔处，端梁接缝补齐，整张屋顶贴图的坐标不被缩短。

静态模型预算（不含阴影、反射等重复渲染）：

| 范围 | 平面箱体 | 立体箱体 | 保持项 |
|---|---:|---:|---|
| 20 英尺单箱 | 202 三角形 | 2,234 三角形 | 外部碰撞尺寸 |
| 道具展示场 | 2,662 三角形 | 6,726 三角形 | 20 材质批次、10 碰撞体 |
| 完整地图 | 61,800 三角形 / 57 批 | 108,888 三角形 / 65 批 | 447 个碰撞体逐对象一致 |

新增批次来自宏观/细节法线材质的分开使用。增加的几何成本有实测记录，不能将其说成没有性能代价；远景货箱保留原预算。

M4 的机匣开口与枪机相对运动一起检查：原生空仓换弹 84% 时后拉 6.7 cm，90% 时归位，取消动作也归位；铭文落在下机匣实体面。导轨与瞄具补连续支承，瞄准轴和手部握点不移动。结构近照隐藏双臂用于观察，枪机运动仍来自正式换弹逻辑，不用手动挪动零件冒充动作效果。

### 后期：处理边缘与高光，同时控制代价

末端抗锯齿位于输出色彩变换之后，对已经合成的世界和武器共同处理。锐化限制在局部颜色范围内，避免高反差边缘出现白边；颗粒在抗锯齿之后叠加。新增一个全屏末端通道，不增加常驻渲染目标。

抗锯齿采用 Three.js 的完整边缘搜索，三档搜索预算分别为 6 / 4 / 3 步，亚像素混合为 0.6。复核包含细栏杆、枪械和细小中文字；锐化只限制自己的增量，不裁剪抗锯齿已经恢复的边缘颜色。

辉光首层使用九点取样与亮度权重，降低极小亮点对整片辉光的影响，复用原有通道和纹理。光雾只是重新分配原有步数；阴影使用本项目 Three.js r186 的硬件 PCF。原作旧式阴影纹理接口不能直接移植，因此这里不声称实现 PCSS 或真实软阴影追踪。

## 展示场复核方法

- 材质：`?lab=mats&shot=1&seed=4207&t=2`，切换颜色、法线、粗糙度、金属度、表面遮蔽和锈层；在完整材质视图调湿度。
- 箱体：`?lab=props&cam=cargo&shot=1`，切换「立体箱体」。它会重开当前场景并保存相机，随后等待 `__lab.ready`。
- 后期：`?lab=render&cam=edges&shot=1`，分别开关抗锯齿、锐化；切到局部视角比较阴影和光雾。效果关闭时保持其余条件相同。
- 武器：`?lab=weapon&shot=1`，检视 M4 并拖动换弹进度，观察开口、枪机、手指和弹匣。
- 实战：`npm run test:browser` 和 `npm run test:feedback` 检查正式游戏状态；`npm run test:lab` 覆盖九模块。

本轮专用检查为 `npm run test:surfaces`、`npm run test:post`。`npm run compare:visual` 在相同种子、时间、画质、视角和 1600 × 1000 窗口下生成 1.3/1.4 对照图，需要本地保留的 1.3 基线文件。纹理、几何和程序数量检查用于发现增长；截图差异仅证明开关生效，美术效果仍需实际观察。不同 GPU 的像素和耗时不保证相同。

暂停或截图模式的链接记录当前观察时刻，启动预演上限为 30 秒；超过时 `snapshot.urlTimeClamped=true`，长过程需要重放相同的 action/step。页面退出会释放整套后期资源。

最终运行记录见 `validation.json`，图像与逐项原始日志保存在本机 `artifacts/v14/`。
